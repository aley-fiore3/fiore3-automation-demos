# What Should You Automate First?

A prioritized checklist for small businesses. Start at the top — each level builds on the last.

## Level 1: Stop the Bleeding (Week 1)

These are the tasks that eat hours every week and have simple automation solutions.

- [ ] **Email responses** — Set up templates/canned responses for your 5 most common email types
- [ ] **Scheduling** — Use Calendly or similar instead of the "when are you free?" email chain
- [ ] **Invoice creation** — Template in your accounting software, not manual each time
- [ ] **Social media posting** — Batch create, schedule with Buffer/Later/Hootsuite
- [ ] **File naming and organization** — Consistent naming convention, stop searching for things

## Level 2: Build the Foundation (Month 1)

These require some setup but pay back every single week.

- [ ] **CRM/contact management** — Every contact in ONE place with notes and status
- [ ] **Project management** — Asana/Notion/Monday for tasks, not email threads and sticky notes
- [ ] **Document templates** — Proposals, contracts, onboarding docs — templatize them
- [ ] **Lead capture** — Form on your website → automatically into your CRM
- [ ] **Client onboarding** — Standard checklist that triggers when a new client signs

## Level 3: Connect the Systems (Month 2-3)

This is where automation gets powerful — systems talking to each other.

- [ ] **Form submission → CRM entry** — Typeform/Jotform → HubSpot/spreadsheet automatically
- [ ] **New client → project setup** — Signed contract → Asana project created with template tasks
- [ ] **Invoice sent → reminder scheduled** — Automatic follow-up if unpaid after X days
- [ ] **Email signup → welcome sequence** — Automated 3-5 email nurture series
- [ ] **Meeting booked → prep doc created** — Calendly booking → Google Doc with agenda template

## Level 4: Scale Without Hiring (Month 3+)

These make you look like a bigger operation than you are.

- [ ] **Reporting dashboards** — Automated weekly/monthly reports from your data
- [ ] **Client portal** — Self-service access to project status, documents, invoices
- [ ] **Content repurposing** — Blog post → social posts → newsletter automatically
- [ ] **Data cleanup** — Scheduled deduplication and validation of your contact lists
- [ ] **Proposal generation** — Template + client data → custom proposal in minutes

## The Rule of 5

Before automating anything, ask:

1. **Do I do this more than 5 times per month?** If not, it's not worth automating yet.
2. **Does it take more than 5 minutes each time?** If not, just do it.
3. **Is the process the same every time?** If it changes constantly, automate the consistent parts only.
4. **Will I still need this in 5 months?** Don't automate temporary processes.
5. **Can I explain it to someone in 5 sentences?** If not, simplify the process first, then automate.
